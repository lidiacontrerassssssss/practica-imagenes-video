## Bitácora

### ¿Qué hace la etiqueta `figure` y por qué es mejor que poner solo `img`?

La etiqueta `figure` agrupa una imagen con su contenido relacionado, como una descripción o pie de foto mediante `figcaption`. Es mejor que usar solo `img` porque añade estructura semántica: permite identificar claramente que la imagen y su texto forman una unidad independiente. Además, mejora la accesibilidad, ayuda a los buscadores y lectores de pantalla a entender el contenido y hace que el código sea más fácil de organizar y mantener.
